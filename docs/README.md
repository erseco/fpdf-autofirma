# Documentación

La documentación de FPDF AutoFirma se divide en cuatro apartados:

- [Uso e integración](uso.md): API pública y flujo hasta el navegador.
- [Arquitectura y coordenadas](arquitectura.md): responsabilidades de las clases y conversión FPDF → PDF.
- [Calidad y cobertura](calidad.md): PHPUnit, PHPStan, PHPCS, CI y umbral del 90 %.
- [Publicación](publicacion.md): tags, GitHub Releases y Packagist.

La librería prepara el PDF y los parámetros PAdES. La ejecución de AutoFirma y la validación criptográfica quedan fuera de este repositorio.
